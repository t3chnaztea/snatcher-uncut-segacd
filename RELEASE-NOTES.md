# Snatcher Uncut v0.9.0-rc1

A selected restoration patch for the English Sega CD release. The Outer Heaven
costume cameos return alongside the dog animation, an adult corpse pose and
selected dates. The original English voices, music and Sega CD Act 3 remain.

The scope is 37 approved change records: 31 text records and six art records.
Most of the English localization remains. Some localized content stays by
design. The opening and database show 1991 while retained speech says 1996.
Read the changelog and known issues before patching.

Extract the player ZIP and open `browser/index.html` for the local browser
installer. The Python/xdelta3 fallback supports additional BIN/CUE layouts.
Both routes validate the original data track. The release contains no game
image or BIOS. Supply your own compatible dump.

The accepted emulator image reached the ending and original credits. Required
fights, transitions, normal saving and a fresh game-menu load passed. Original
audio tracks and pregaps remain unchanged. Original-console testing has not
run, so this is a release candidate.

TECH NASTY developed the patch with AI assistance. The comparison images use
actual emulator captures. Source game data supplied the restored art through
deterministic conversion. No generative image model made replacement game art.

The release includes input checksums, installation instructions, scope and
compatibility notes, credits and source. Report the patch version, source
Track 1 hash, input layout and emulator or device version with a bug report.
Do not attach game images, BIOS files or extracted assets.
